Standalone-Modul ohne externe Abhängigkeiten. Einfach in jedes Projekt kopieren und importieren. Verbindungsparameter können per .env-Datei gesetzt werden — kein Hardcoding in einzelnen Skripten nötig.

.env Konfiguration
# .env
WATCHDOG_URL=http://{{ request.host }}
WATCHDOG_SERVER=mein-server

Mit python-dotenv automatisch laden oder per Systemumgebung / Docker / systemd setzen.

Schnellstart
from dotenv import load_dotenv
from watchdog_client import WatchdogClient, DependencyError

load_dotenv()                   # liest WATCHDOG_URL + WATCHDOG_SERVER aus .env
client = WatchdogClient()       # keine Parameter nötig

# Einfache Meldungen
client.start("backup")
client.stop("backup", kommentar="12 GB in 4m")

# Context Manager (auto start/stop, meldet fehler bei Exception)
with client.run("cleanup"):
    do_cleanup()

# Abhängigkeit prüfen
client.require_success("backup", within_minutes=60)

# Version prüfen
info = client.check_version()
# → {'local': '{{ version }}', 'remote': '{{ version }}', 'up_to_date': True}
API-Referenz
MethodeBeschreibung
report(dienst, status, …) Status melden — start, stop, fehler, update
start / stop / error / update(dienst) Shortcuts für report()
run(dienst) Context Manager: start → stop / fehler bei Exception
last_success(dienst) Letzten erfolgreichen Lauf als datetime abfragen
require_success(dienst, within_minutes) Wirft DependencyError wenn Dienst nicht rechtzeitig lief
check_version() Vergleicht lokale Version mit Server-Version
